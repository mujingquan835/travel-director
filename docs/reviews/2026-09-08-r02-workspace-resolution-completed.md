# R02 阶段总结：工作区解析修复

日期：2026-09-08。范围：只完成 R02。

## 修改

- 显式 `--workspace` 优先于环境变量；显式参数或生效的环境配置无效时立即失败，不回退。空配置也报错。
- 配置支持包目录或包含 local-media-scanner 的仓库根目录，并展开用户目录标记。
- 未配置时先选择当前 Git checkout 的有效包；非 Git 环境检查当前目录。
- 当前 checkout 无效时，候选仅来自关联 Git worktrees 和脚本祖先目录。唯一有效候选可选；多个候选列出路径并报告 ambiguous。
- 删除作者机器目录与固定分支/worktree 名称。
- stdout 仍仅输出包路径，错误写 stderr 并返回非零状态；workflow 说明优先级与 Git HEAD 核对方式。

在有效的 main checkout 中运行默认选 main，不再暗中偏向 feature。需要功能分支时应显式配置其包或仓库路径。
