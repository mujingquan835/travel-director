## 完成内容

- Outro 保留原有 hard_stop、decay、fade 匹配规则，匹配项按路径字典序稳定选择；不受目录顺序影响。
- 新增 `director/sfx_assets.py`：冻结 Hook Riser、Hit 和实际选中的 Outro；存储在项目 `delivery/assets/sfx-<sha256>.<extension>`。
- 新 Runner 时间线 schema 为 1.2.0，sfx_assets 记录角色、来源绝对路径/相对路径、副本相对路径、SHA-256、字节数和对副本实测的时长。
- 复制前后核对读取字节哈希，拒绝空文件、非法格式、库外路径；临时文件完成测量后以不覆盖方式发布，已有损坏副本不会被覆盖。

- JSON 哈希绑定音效资产元数据，现有收据绑定 JSON；完成与恢复时同时校验音效副本大小、哈希、角色覆盖和路径。
- 音效库原文件被修改/删除不会改变已完成版本；冻结副本损坏或丢失返回 blocked，不自动从库恢复。
- 导出 `validate_sfx_assets` 预检函数，返回已校验的角色到冻结路径映射，供后续渲染集成使用。
- 旧 schema 1.0.0/1.1.0 继续读取，但不声称冻结音效；需要可验证音效时创建新的时间线修订。
