# R06 纠正阶段总结：恢复规划型 Skill 定位

## 用户纠正与本轮范围

用户拒绝旧 R06 的卡点、素材选择、大量重复及自动剪辑路线。快速模式应拆解音乐并建议画面内容、快切与停留；不是裁切音乐，也不是剪辑画面。慢速模式只能用代表静帧占位，不能拼接动态素材。

本轮纠正 R06；R07 仅修改后续任务定义，未开发。慢速静帧展示未在本轮新增，不能把边界说明写成已实现功能。

## 修改

- 正式 Runner 的 `--place-footage` / `--build-preview` 隐藏并停用，调用在素材清点或项目写入之前返回 blocked 和替代命令。旧模块只保留明确拒绝执行的兼容入口，移除自动选片、源入出点和渲染实现。
- 新增 `--build-guide`，复用冻结音乐分析、创意分段和已有收据，输出音乐时间、画面建议、叙事目的、切换建议及理由、分析候选及置信度、节拍参考和素材缺口。
- 原曲时间仅作参考，节拍不等于必切点；不分配最终素材，不写源入出点，不裁切音乐、不混音、不生成视频。
- 分段沿用现有创意方案，同时列出重叠音乐分析子段；不冒称精确乐句检测。低置信度保留待试听，跨音乐段的建议不能由短暂段尾决定整段节奏。创意高潮缺少音乐分析支持时明确提示冲突。
- 新产物位于 `guidance/<内容指纹>/`，JSON、Markdown 和收据绑定内容。幂等复用、损坏阻塞，新音乐/时间线修订不复制旧 guidance。
- 快速网格文字改为建议参考，撤回每个边界必须对齐切换的措辞。旧时间线及实验视频保持原字节，旧阶段总结加上用户拒绝和路线撤回说明。
- 更新 Skill、workflow、README 和修改清单。R07 改为音频包装建议与配置边界，不接入实际混音；不得绕行原型命令渲染。已同步全局 Skill，旧安装由安装器备份。
