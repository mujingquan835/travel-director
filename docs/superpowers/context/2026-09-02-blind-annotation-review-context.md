# 旅行导演独立盲测标注页上下文

日期：2026-09-02

分支：`feature/local-media-scanner-v0.1`

## 本轮完成

- 新增预测隔离的中文独立标注页，只渲染冻结 blind split 的 12 条素材。
- 一个页面内明确分离两层标签：
  - 画面事实：8 个现有 Ground Truth 字段。
  - Brief 相关导演标签：素材桶位和导演职责。
- 页面不展示系统识别、桶位或导演职责预测，避免污染独立人工标准。
- 导出单个 `blind_annotation.json`，并用 Brief SHA-256、source manifest SHA-256 和 blind membership SHA-256 绑定。
- 新增 CLI：
  - `render-blind-annotation-review`
  - `validate-blind-annotation`
- 新增一致性规则：“无法判断”不能与具体内容同选；“有人”不能与“无人”同时成立。
