状态：本地结构检查通过，但 macOS 剪映 11.4.0 实际打开失败，客户端报“无法打开草稿 / 草稿内容已损坏”。

使用 pyJianYingDraft commit c3318066d964744e2bfc66f75c71745fe8cea52a，在独立 Python 环境生成。

- 1920×1080、30 fps、12 秒。
- 三段真实画面各 4 秒，源音量 0。
- 独立音乐轨 12 秒，音量 0.35。
- Whoosh 从 0 秒开始、2.16 秒、音量 0.8。
- SubDrop 从 7.6 秒开始、2.94 秒、音量 0.75。
- 三条独立音频轨，六个片段，引用原始本地素材，未复制大视频；移动原素材会失联。

## 客户端结果
新草稿文件夹已放入本机剪映草稿目录：TD-P0-12s-code-20260909-v2。它能出现在首页，但打开后报草稿损坏。结论是该生成器的旧式明文 `draft_content.json` 布局不兼容本机剪映 11.4.0；不再通过补齐若干 sidecar 文件猜测修复。

本次使用上游标准 draft_content.json 与 draft_meta_info.json 结构，没有猜测修改加密载荷或全局草稿索引。本机既有草稿使用 draft_info.json，这个差异仍需兼容验收，文件生成成功不代表客户端已支持。
